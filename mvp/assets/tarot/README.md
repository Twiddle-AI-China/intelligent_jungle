# Seasonal tarot backgrounds

Original project-owned SVG assets, drawn in code on 2026-07-22.

- Three-token palette only: paper is supplied by the renderer; SVG strokes use `ink`, accents use `accent`.
- The central band stays intentionally sparse for the trunk, birds, and Sequence nodes.
- Seasonal motifs: spring sprout/star wheel, summer fern/sun dial, autumn grain/crescent, winter bare branch/crystal.
- Runtime season crossfade, linear day/night overlay, grain, celestial assets, and beat flash remain separate renderer layers.
