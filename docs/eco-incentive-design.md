# 生态计分：树的偏好节奏

> 2026-07-18。v2——推翻 v1 的多套资源机制（蜜/巢温/根压/虫群/腻性，过度设计），
> 回到一个机制：**每棵树偏好一种起落节奏，得分 = 行为与偏好的匹配度**。

## 1. 唯一机制

每棵树对「鸟怎么用它」有一个偏好，用三个可观测量描述（全部是已有状态，
不引入任何新资源概念）：

- **换枝频率**（次/日）
- **平均驻留时长**（秒）
- **同枝群聚数**（只）

树的得分 = 当日实际值落在偏好区间内的程度（区间内满分，偏离线性衰减）。
得分可视化为树的长势/心情，替代原 foliage 的抽象健康。

> 单位修订（2026-07-19，随 rebuild-plan §3.5.3 音乐单位化）：
> 「平均驻留」以**拍**计、「换枝频率」以**次/循环**计——变速不改变评分。
> 实现：`mvp/src/economy.js`（已交付，7/7 测试绿，待接线进日评估）。

## 2. 四棵树的偏好参数（即声部性格）

> 单位修订（2026-07-19，随 §3.5.3 音乐单位化）：全表改用音乐单位。
> 1 昼夜 = 1 循环 = 4 小节 4/4 = 16 拍；换枝频率以**次/循环**计、
> 驻留以**拍**计（bass 以循环计）——变速不改变评分。数值是起始偏好带，
> 全部进 config 可调。

| 树/声部 | 换枝频率（次/循环） | 平均驻留 | 群聚 | 附加偏好 |
|-|-|-|-|-|
| 飞羽树 melody | 高（8–16） | 短（0.5–2 拍） | 1 只 | 不喜欢连续重复同一枝 |
| 和鸣树 pad | 极低（0–1） | 长（≥8 拍） | 每枝 1–2 只、铺 3–5 枝 | **换就一起换**：换枝只在日界成批发生 |
| 低吟树 bass | ≈0（只在换季，即每 2–8 循环一次） | 极长（≥1 循环） | 1–2 只限低枝 | 换季日必须挪一次 |
| 微光树 texture | 中（4–8） | 中短（1–4 拍） | 1 只 | 喜欢在同一枝反复起落（离开又回来） |

「偶尔一起换」不需要新机制：pad 的偏好就是「日内换枝扣分、日界成批换枝加分」，
这直接复用 Phase 1.5 已有的日界变奏（家枝变异）。

## 3. Agent 怎么用得分

黄昏日评估（已有）多一个输入：当天得分和三个观测量各自的偏离方向。
计划理由直接引用它：「今日换枝 2 次低于偏好带，明日活跃窗放宽」。
LLM 个性层同样只拿这几个数做偏置。变奏的动力 = 修正偏离 + 已有的日界小变异，
不另设反停滞机制——先跑起来听，不够再说。

## 4. 实施

Phase 1.7：`mvp/` 单树实现该计分（melody/pad 两 profile 用各自偏好带），
侧栏显示三观测量 + 得分，日志理由引用偏离。参数全进 config。
四树偏好表在 Phase 3 随四树一起落地。

## 5. 验收

- 切到 melody：得分驱动下短促跳枝不重音；切到 pad：整日稳栖、日界成批换位。
- 日志能看到「偏离 → 明日修正」的因果句。
- 参数表（偏好带）改一改，听感跟着变——调音乐 = 调偏好带。

## 6. 和声决策权：master 独有（2026-07-18 江南提问后定）

**分权原则：和声是全局结构，只能有一个作者。**

- **flock agent（四个）**：只管自己声部的行为编排（家枝变异、活跃窗、
  对偏好带偏离的修正）。**永远不碰和声**——四个 agent 各自定调必然打架。
- **master agent（一个，「季节/天气」角色）**：独家决定
  ① 明日走 progression 的哪一步（通常顺走，可跳步/停步）；
  ② 换季时机（在 config 给的范围内提前或延后，如 2–8 天/季）；
  ③ 季节色彩变体的选择（春 major 系/夏 sus 系/秋 dorian 系/冬 minor 系）。
- **约束：agent 只点菜，不发明菜**。progression 候选集、色彩变体集、
  季节天数范围全部是 config 里人定的菜单；master 只做选择与调度。
  这保证任何决策序列都在可听范围内。

**master 的得分（决策依据），只用三项已有观测量，不引入新概念：**

| 项 | 含义 | 效果 |
|-|-|-|
| 均衡 | 四树（现单树）当日得分的均值与最低值都在健康带 | 某声部连续低分 → 当前和弦地形不适合它的性格 → 倾向换 progression 步/色彩 |
| 新鲜 | 同一色彩/同一进行连续天数越多，此项得分递减 | 丰年季节长、待腻了换季——季节天数由此涌现，而不是写死 |
| 平稳 | 每次只改一个维度（先换步再换色彩），换季后有冷却天数 | 大结构变化是低频事件，听感不乱 |

**时序**：master 与 flock 同一条流水线——第 N 天全天复盘第 N−1 天，
决策在第 N+1 天黎明与换和弦一起生效。LLM master 是个性层（选菜口味），
代码兜底 = 顺走进行 + 到期换季（G7 不变）。
