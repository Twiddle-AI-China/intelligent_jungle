# Latent Cosmos Synth：世界观与基本玩法

> 玩法基线：2026-07-14 Boids 重构版。后续可以调数值和声音映射，不再混用“鸟、声源、Voice”三个概念。

> 当前实现边界：Web 版还是 BRAVE 离线纹理播放器，不是实时 decoder；XY 不是 latent 投影。本文描述稳定的产品关系和目标玩法，已实现程度以 [当前声音链事实边界](audio-fact-boundary.md) 为准。

## 一句话

Latent Cosmos Synth 的目标是一件用鸟群行为演奏神经声音的乐器。当前原型验证了世界玩法和离线神经素材接入，还没有完成实时 latent 解码。

你不是逐个调整合成器参数，而是在世界里增加鸟、放置障碍和引导鸟群。鸟群怎样聚集、转向和绕行，会直接改变声音。

## 三层关系

| 世界里的东西 | 音频里的含义 | 数量规则 |
|---|---|---|
| 鸟群类型 / Species | 一个稳定的神经声源身份 | MVP 提供脉冲、共鸣、纹理三类 |
| 一群鸟 / Flock | 一个可以独立发声的 Voice | 初始 3 个，最多 6 个 |
| 一只鸟 / Boid | Voice 内部的行为粒子 | 每群初始 7 只，最多 32 只 |

一只鸟不单独启动一个 decoder。否则鸟一多，CPU、混音和听觉层次都会失控。

“加鸟”只增加当前声音群的密度、能量和内部复杂度。“新增声源”才增加一个真正的 Voice。达到 6 Voices 后，界面明确拒绝继续新增，不进行隐藏的 voice stealing。

## 你能做什么

### 加鸟

先选择脉冲群、共鸣群或纹理群，再点击世界。

当前结果：该群体多一只鸟，控制状态中的 density、能量和 pulse 发生变化，但 Web 纹理播放器只听得到其中部分增益和节奏变化，不会凭空多出一个声部。

### 放障碍

点击世界放下障碍。鸟会提前转向、绕开障碍。

目标结果：绕行压力带来瞬态、粗糙度和噪声变化。当前 Web 版主要通过运动与 pulse 间接改变声音；roughness/noisiness 尚未完整接入，因此障碍的可听因果还没有通过。

### 引导

在鸟群附近拖动，给局部对象一个方向。

目标结果：Alignment 把方向传给同群伙伴，并通过经过听测的映射推动 latent 音色变化。当前 Web 版只用水平方向部分控制纹理交叉淡化、滤波与少量播放速率。

### 擦除

擦掉一只鸟或一个障碍。每个声音群至少保留两只鸟，避免误操作让整个 Voice 消失。

### 新增声源

按“新增声源”创建一个新的鸟群和音频 Voice。新群使用当前选择的 Species，可以与已有群共享音色类型，但拥有独立位置、运动、节奏和声像。

## 三条 Boids 规则

三条规则一直运行，不是用户需要选择的三个效果器。

- Cohesion：同群的鸟靠近共同中心；目标是让声音形成可追踪声部。
- Alignment：同群的鸟逐渐共享方向；当前只有水平方向部分进入声音。
- Separation：所有鸟在距离过近时避让；视觉空间成立，听觉层次尚待完整映射和听测。

障碍是环境，不是第四条群体规则；加鸟、引导和擦除是用户编辑世界的方式，也不是新规则。

## 运动怎样变成声音

| 鸟群状态 | 目标映射 | 当前 Web 实现 |
|---|---|---|
| 群心左右位置 | 声像位置 | 已接入 |
| 群心上下位置 | 待听测后定义 | 未接入 |
| 平均运动方向 | latent / 音色变化方向 | 水平方向部分控制 brightness |
| 平均速度 | 能量、脉冲和变化速度 | 部分接入 |
| 群体散布 | 粗糙度、噪声感和立体宽度 | 只计算控制状态 |
| 鸟的数量 | 密度和内部活动量 | 部分接入增益与 pulse |
| 绕障碍压力 | 瞬态、粗糙度与频谱避让 | 通过运动与 pulse 间接接入 |

目标映射方向固定。模型验证可以改变映射曲线或可用 latent 路径，但不能让同一个视觉动作每次代表不同含义。当前未接入的维度不能写成已经可听。

## 为什么仍然是乐器

- 用户必须持续观察、增加、删除和引导，而不是按一下等待生成。
- 相同的世界状态和动作可以重放。
- 鸟群有自身惯性，松手后不会立刻停住。
- 世界会产生细节变化，但工具和结果方向稳定。
- 声源数量、鸟数和障碍都有清楚上限。

## MVP 边界

- 3 种 Species；
- 初始 3 Voices，最多 6 Voices；
- 每群初始 7 只鸟，最多 32 只；
- 加鸟、障碍、引导、擦除、新增声源；
- MIDI 当前改变世界中的和声中心和能量；BRAVE 纹理音高尚未接入；
- 一个可追溯到真实 BRAVE 模型的离线声音材料链路。

第一版不做繁殖、死亡、捕食、气候、自动作曲和无限 Voice。先证明基本工具能形成可看懂、可听懂、可复现的演奏方法。
