# MVP 5 分钟体验指南

## 开始

1. 运行 `npm run dev`，打开 <http://localhost:4173>。
2. 等待三套模型显示 `Decoder ready`，点击“唤醒声音”。初始三个 Voice 应分别显示 `brave-16d`、`fsl10k-16d`、`mrp-8d`；显示失败时输出保持静音。
3. 先观察 20 秒：初始应有 3 个不同颜色的声音群、共 21 只鸟。
4. 在“世界信号”下方确认能看到每个 Voice 的实时 dB、`M` 和 `S`。先逐个按 `S` 独奏，记录固定音来自哪一群；`M` 可暂时静音该群。
5. 画面应明确显示七条带音名的横向 Dorian 区域和一条标为 `PULSE` 的纵向扫线；没有含义不明的群体圆圈。

## 1. 加鸟是否真的改变声音

选择“脉冲群”和“加鸟”，在它附近连续增加 5 只鸟。

应该发生：右上角 Boids 数增加，Voices 数不变；脉冲群的声音密度和活动增加，另外两群身份不变。

## 2. 障碍是否是声音机制

选择“障碍”，在一群鸟前方放一个圆。

当前预期：鸟提前转向绕行；群心改变主要音色方向，平均速度与避障压力改变次级 latent。若只有画面变化、听不出变化，仍记录为听感失败。

## 3 分钟模型 A/B

保持同一世界状态，在 Voice 行内切换 `brave-16d`、`fsl10k-16d`、`mrp-8d`。也可让三个 Voice 同时使用不同 decoder。独奏同一个 Voice，重复相同方向的引导，记录音色范围、动作可预测性、瞬态/噪声伪影和控制延迟。

## 空间旋钮与复音

先只改变巡航速度、转向力度、感知半径和 Boids 三力，确认鸟的运动先变化，声音随后变化。再降低分群距离或最小成组：一个 Flock 空间分裂后应显示多个 note labels，最多四个；重新聚拢后应回到一个 note。面板不直接提供 pitch 或 duration 旋钮。

## 3. 引导是否可学习

选择“引导”，在一个声音群上从左向右拖动。等它恢复后重复同一手势。

应该发生：局部鸟先转向，随后同群伙伴跟随；群心在 checkpoint 曲面上移动，音色变化方向两次大致相同。跨过横向区域时 Voice 音名和实际移调改变。

## 4. 音高和节奏是否真的进入声音

先独奏一个 Voice。观察 PULSE 扫过该群的鸟：声音应出现有衰减的触发；群体紧密时较集中，散开时形成 flam。再用引导把群体推入另一条音高带，Voice 列表的音名和听到的音高都应改变。点击 D、E♭ 等根音按钮后，整张音高场随之移调。

## 5. 删除是否可控

选择“擦除”，删除刚才的障碍，再删除几只鸟。

应该发生：障碍或单只鸟消失；系统不会因误擦一只鸟而静默整个 Voice，每群至少保留两只鸟。

## 6. Voice 扩展是否诚实

选择一种声音群，连续按“新增声源”。

应该发生：每次新增一整个 Flock 和一个音频 Voice；最多到 6。第 7 个被明确拒绝，而不是偷掉旧 Voice。

- 三种 Species 是否容易区分：____
- 哪一步仍然像动画，而不像乐器：____
- 固定音来自哪个 Voice，独奏时大约多少 dB：____

自动安全检查不能替代人工听测。模型未由人耳确认前，不宣称音质或音乐性已经通过。
