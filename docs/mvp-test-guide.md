# MVP 5 分钟体验指南

这不是“听一段 AI 自动作曲”。你要做的是带领 6 个持续存在的声音对象，并观察同一个动作能不能产生稳定、可学习的结果。

## 开始前

1. 在项目目录运行 `npm run dev`。
2. 打开 <http://localhost:4173>。
3. 点击“唤醒声音”。页脚如果显示 `BRAVE 神经声音`，说明正在播放本次训练模型生成的真实神经声音；如果显示 `Web Audio 替身声源`，只能测试玩法，不能评价模型音质。
4. 先不操作 20 秒，记住世界自己运行时的声音。

建议佩戴耳机，并先把系统音量调低。

## 三个必须听出的区别

### 1. 聚合 / Cohesion

选择“聚拢”，在对象较密集的位置缓慢拖动 10 秒，然后松手。

你应该听到：节奏和和声语境更像一群人在一起演奏，但高低声部和音色身份还在。

失败信号：所有声音变成同一个声音，或者完全听不出变化。

### 2. 对齐 / Alignment

选择“引导”，从一个对象附近向同一方向连续划动 2–3 次，然后松手。

你应该听到：音色或能量变化从局部传向其他对象。大家共享趋势，但不是复制同一状态。

失败信号：没操作时仍不停发生同样的集体变化，或者所有对象立刻完全同步。

### 3. 分离 / Separation

选择“推开”，在两个靠近的对象之间来回拖动 5–10 秒。

你应该听到：它们在音域、明暗、节奏或左右位置上逐渐让位，整体更清楚。

失败信号：只是整体变小声、对象被静音，或者音区无规律乱跳。

## 乐器性测试

1. 用“扰动”把世界弄乱，再用“聚拢”把它带回来。
2. 选择“引导”，做一条自己记得住的手势。
3. 等世界稳定后，重复同一手势。
4. 判断第二次是否出现方向相近、细节略有不同的结果。
5. 每次松手后听 20 秒：世界应继续演化并逐渐回稳，而不是立刻停住或无限随机变化。

如果你能第二次主动做出相近结果，它才开始像乐器；只有“每次都很惊喜”还不够。

## 记录四句话

- 我最容易听出的规则是：____
- 我最难听出的规则是：____
- 我成功复现的动作是：____
- 最像玩具、生成器或失控系统的时刻是：____

模型音质的人工听测尚未自动判定。没有亲耳确认前，页面中的 `BRAVE 神经声音` 只代表声音确实来自导出的模型，不代表模型已经通过听感验收。
