# 生态音序器：四棵树

> 状态：**当前实现版**（2026-07-18，对应 `feat/four-trees` 分支代码）。
> 飞书设计稿（含更多讨论与已否决方案）：https://twiddle-ai.feishu.cn/docx/IKXCdw0GUoRzKOxem3OcMvpqnyh
> 本文只描述**现在代码里真实存在的东西**；淘汰项见 §9。

## 0. 原则

1. **agent 是生物，不是作曲家**——目标函数只用生存词汇定义，音乐是副产品。
2. **生态要成为音序机制本身**，不能只是视觉皮肤。
3. **规则与声音脱钩**：鸟种属性、agent 规则、树健康**只引用生态中间属性**——栖驻、
   种群、活跃度、树健康（foliage）、虫害（pest）、昼夜、季节，全部可视。音乐后果由固定的
   映射层（`src/eco/mapping.js`）单向翻译。agent 的世界里没有「音」这个字。

## 1. 世界 = 四棵树（2×2）

四棵树铺满视野。一棵树 = 一个声部；树是乐器，鸟群是演奏者，agent 是本能。
每个物种一个生态职能动词：

| 树 | 鸟种 | 生态职能 | 映射层接入的声部 |
|-|-|-|-|
| 低吟树 | 鹈鹕 | **压枝**：一栖很久，重栖损耗树健康 | bass（长低音） |
| 和鸣树 | 斑鸠 | **沃土**：稳定栖驻缓慢回复己树健康 | support（pad 铺底） |
| 飞羽树 | 百灵 | **传粉**：穿飞时沿途树健康微增 | ornament（lead） |
| 微光树 | 啄木鸟 | **啄虫**：清除己树虫害 | shimmer（pluck） |

## 2. 三层结构：生态层 → 映射层 → 音乐底层

| 层 | 内容 | 谁在这里活动 |
|-|-|-|
| **生态层** | 鸟与四棵树。状态：栖驻（哪根枝、几只、多久）、种群数、活跃度、树健康、虫害、昼夜相位、季节 | 规则、经济流量、agent、用户交互 |
| **映射层** | 固定单向翻译（`src/eco/mapping.js`）。agent 永不触碰 | 无人 |
| **音乐底层** | 和弦内量化、音域带、枝干的和弦内音生成 | 无人 |

**枝干 = note**：每棵树的枝干是该声部音域带（`ROLE_BANDS`）内的和弦内音，
按音高从左到右排开（低→高），音域带跨约两个八度 → 每棵树一条完整可弹的和弦音阶
（bass 6 枝、其余 4-5 枝）。换和弦（换季）→ 枝干重构（`rebuildBranches`）。

**映射层对照表**：

| 生态量 | 音乐参数 |
|-|-|
| 栖驻的枝干 | 音高（该枝的 midi） |
| 同点栖鸟数（≤3） | 力度三档（`velocityFromPerchCount`） |
| 驻留时长 | 时值 |
| 光环 8D 运动 | 音色（filter/Q/detune/delay/level） |
| 树健康（foliage） | 该声部丰润度：混响发送 + 谐波增益 |
| 虫害（pest） | 该声部杂质：噪声 + 失谐 |
| 昼夜相位 | 滤波宏 + 密度上限 |
| 季节 | 和弦色彩（春大三/夏sus4/秋小七/冬小三） |
| 全局健康 | 全局频段亮度、lofi mix |
| 镜头距离 u | 混音焦点（近树前置，他树衰减） |

## 3. 发声：鸟落枝即鸣

**没有节拍器，没有 XY 时间线，没有扫描线触发**（pulsePosition 已删）。
鸟落在哪根枝，就发那根枝的音；栖鸟越多越响，驻留越久音越长。
触发由栖落事件驱动（`triggerPerchedBirds`）：每根枝上栖着的鸟 → 一次发声。

**循环往复 = 日夜交替**（唯一的大循环）：白天鸟活跃、夜里归栖（dwellUrge 升高），
黎明跨过时晨鸣（各群短暂齐活跃）。季节由 master 或用户切换（=和声色彩）。

## 4. boids：一套鸟群的三重身份

只有一个世界（`src/world.js`），每群鸟绕自己的树生活，一部分栖着一部分飞着：

1. **栖着的鸟 = 乐谱**（枝干音符的存亡/力度/时值）。
2. **飞着的鸟 = 音色**（绕树冠的光环，8D 关系 → 合成器参数）。
3. **起落 = 编曲的变化**（agent 旋钮、昼夜、用户引导改变栖/飞比例）。

## 5. 视角：单 canvas camera zoom

编排层与贴近层是同一世界的两个焦距（`camera {cx, cy, scale, u}`）：
- 双击某树 → 镜头贴近（u→1），其他树淡出为远景；键盘 A–K = 召唤一只飞鸟落到
  按音高排序的第 N 根枝（A=最低音枝，K=最高音枝）= 写谱。贴近时枝干标出音名。
- Esc → 缩出（u→0）且自动交还（controller 回 AGENT）。

## 6. 生态经济与 agent

**五流量**（`src/eco/economy.js`）：每棵树的健康（foliage）积分——
进：沃土（斑鸠安栖）、传粉（百灵穿飞）、休养（低占用自愈，夜间加速）；
出：压枝（鹈鹕重栖）、过载（占用超容）。虫害独立滋生、随季节变速、唯啄木鸟可清。

**种群 agent 5 条规则**（`src/eco/agent.js` `flockPolicy`，纯生态词汇）：
作息（夜间归栖）/ 体力（energy 低归栖）/ 本职（啄虫/沃土/压枝自限/传粉）/
应答（邻树兴奋跟随）/ 兜底 cruise。输出 `dwellUrge`——密度呼吸是 agent 的活，物理层不强制。

**LLM 个性层**（`src/eco/llm-agent.js`）：MiniMax `abab6.5s-chat`，同样 5 条规则 prompt，
严格 JSON 输出 `{dwellUrge, reason}`，2s 超时；失败/掉线回退代码兜底（G7），循环永不停。
`configureLlm(apiKey)` 注入。

**Master agent（自然，中度干扰目标）**：健康保持带内 + 对「过稳」惩罚。
指令：`set_population` / `set_daynight` / `set_scale` / `set_bpm` / `spawn_pest_wave`
（扰动限速：强度上限 + 冷却）。代码兜底 `masterPolicy`，LLM 侧由玮圣服务接入。

## 7. 声音引擎

`src/audio-engine.js` Web Audio 轻量合成器（Spark 上线前替代 BRAVE neural decoder，
映射契约不变）：每棵树一个 SynthVoice（主 osc + sub + 谐波 osc + 噪声 + filter +
gain + delay + pan + focusGain）。生态映射：richness→混响/谐波、impurity→噪声/失谐、
focusGain→混音焦点、master filter+lofi waveshaper→全局亮度/lofi。

## 8. 前端

单页（`index.html` + `src/style.css` + `src/app.js` + `src/eco/storybook-renderer.js`）。
暖阳田园绘本风：2×2 四棵写实绘本树、远山草甸、昼夜天空、季节粒子、写实鸟（栖/飞两态）。
侧栏：天气（气温/季节/master 徽标）、林子（四棵树卡片）、长势（健康/虫害）、键盘→树枝。
全部文案为克制自然的中文。
