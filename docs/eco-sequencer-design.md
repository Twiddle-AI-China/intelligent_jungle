# 生态音序器 v3.3：四棵树的经济

> 状态：设计稿（2026-07-18，v3.3）。
> 飞书同步：https://twiddle-ai.feishu.cn/docx/IKXCdw0GUoRzKOxem3OcMvpqnyh
> v3.1→v3.2：去掉林地概念，只有四棵树；砍 chronotype，换成物种↔树的生态经济
> （啄虫/传粉/沃土/压枝/虫害五个流量）；映射层补全（含客音符、虫害音、镜头混音焦点）。
> v3.2→v3.3：加入对抗性张力——master 目标改为「中度干扰」并获得扰动工具（必做）；
> 虫群可升级为第五个生存 agent（P4 可选）；明确不做「恶意双云端对抗」。

## 0. 原则

1. **agent 是生物，不是作曲家**——目标函数只用生存词汇定义，音乐是副产品。
2. **生态要成为音序机制本身**，不能只是视觉皮肤。
3. **规则与声音脱钩**：HP 增减、鸟种属性、玩法规则**只引用生态中间属性**——栖驻、
   种群、活跃度、树健康（繁茂度）、虫害、昼夜、季节，全部可视。音乐后果由固定的
   映射层单向翻译。agent 的世界里没有「音」这个字。

## 1. 世界 = 四棵树

四棵树，没有别的舞台。一棵树 = 一个声部；树是乐器，鸟群是演奏者，agent 是本能。
每个物种一个**生态职能动词**，物种↔树的作用构成整个游戏的经济：

| 树 | 鸟种 | 生态职能 | 经济角色 | 映射层接入的声部 |
|-|-|-|-|-|
| 低吟树 | 鹈鹕 | **压枝**：体型大、一栖很久，重栖损耗树健康 | 开销（奢侈品） | bass（长低音） |
| 和鸣树 | 斑鸠 | **沃土**：恋巢安栖，稳定栖驻缓慢回复己树健康 | 进项 | support（pad 铺底） |
| 飞羽树 | 百灵 | **传粉**：轻捷爱飞，穿飞时沿途树健康微增 | 进项 | ornament（lead） |
| 微光树 | 啄木鸟 | **啄虫**：短飞短驻，清除所栖树的虫害；唯一虫害对策，会**串门出诊** | 防御 | shimmer（pluck） |

- **虫害**是第五个流量（威胁）：每棵树随时间滋生虫害（可视为树干斑点/变色），
  随季节变速（夏快冬慢），只有啄木鸟能清。没鸟照料的树被虫害自然拖垮
  ——「弃树枯萎」无需专门规则。
- **养得起鹈鹕 = 生态富足**。bass 声部的存在本身是张力来源：它消耗健康，
  健康不足时鹈鹕必须节制（bass 自动变疏）——低音密度被生态自限。
- **chronotype 已砍**（v3.1 的作息表方案）：声部轮替不靠排班，靠经济涌现
  ——虫害涨了啄木鸟才忙、树弱了斑鸠才久栖、富余时才养得起鹈鹕。
  只保留全局昼夜（§5）。
- 脱钩示范：啄木鸟「短飞短驻」是生态习性，映射层自然翻译出断奏
  ——不存在「啄木鸟=短音」的声音规则。

## 2. 三层结构：生态层 → 映射层 → 音乐底层

| 层 | 内容 | 谁在这里活动 |
|-|-|-|
| **生态层** | 鸟与四棵树。状态变量：栖驻（哪根枝、几只、多久）、种群数、活跃度（栖飞比与光环运动）、**树健康=繁茂度**（每棵树）、**虫害**（每棵树）、昼夜相位、季节 | 规则、经济流量、agent、用户交互——全部只在这层 |
| **映射层** | 固定的、手工调校的单向翻译（下表）。agent 永不触碰 | 无人。它是「乐器的构造」 |
| **音乐底层** | 和弦内量化、音域带、微变化预算、G1/G2 时钟 | 无人。保证映射输出的任何组合都成立 |

**树健康（繁茂度）**：每棵树一个标量，慢速积分五个流量（§1），可视化为枝叶茂盛度。
它是「这棵树被照料程度」的可视记忆。**全局健康 = 四树健康均值**（min 触发报警），
不再有独立的林地/HP 实体。

**映射层对照表**（v3.2 补全）：

| 生态量（全部可视） | 音乐参数 |
|-|-|
| 栖驻位置（枝干 × 步位） | 音高 × 拍位 |
| 同点栖鸟数（上限 3） | 力度三档 |
| 驻留时长 | 时值 |
| 光环 8D 运动（紧密/对齐/扩张/动能/环流） | **BRAVE 音色**（Spark 前由 Web Audio 合成器代驾，映射契约不变） |
| 树健康（繁茂度） | 该声部丰润度：混响发送、谐波丰度；枯萎 = 干瘪 |
| 虫害程度 | 该声部「杂质」：噪声成分、轻微失谐——树病了听得出来 |
| 客鸟停驻（啄木鸟串门） | **客音符**：host 树声部里的临时装饰层（客鸟有视觉标记） |
| 树间飞行（传粉航线） | 不发声，仅视觉（候选：极轻的风声，开放问题） |
| 昼夜相位 | 滤波宏 + 整体密度上限（夜暗而稀） |
| 季节 | 和弦色彩（春大三/夏 sus4/秋小七/冬小三）→ 枝干重构；同时调虫害滋生率 |
| 全局健康（四树均值） | 全局频段亮度、lofi mix 程度（枯萎 → cutoff 暗沉、lofi 加重） |
| 镜头距离 u | 混音焦点：近树声部前置，他树衰减 |

「生态健康 ⇔ 编曲良好」的对应关系**只存在于这张表的设计里**：
均衡的栖驻翻译出配器均衡，串门出诊翻译出声部间的动机交换，经济收支的起伏
翻译出段落起伏。规则和 agent 从不引用右列。

## 3. 树 = 乐器：枝干即音符行

映射层的「下行」：和声决定树的形态。

- **枝干 = 和弦内音**：声部音域带（`bandForChord`）内每个和弦内音长一根枝干，
  高度 ∝ 音高。枝干只长在和弦内音上——「怎么落都不难听」在树的形态里就位。
- **沿枝方向 = 循环时间轴**：16 步格点。一棵树冠 = 该声部的钢琴卷帘。
- **鸟落枝 = 音符**：映射层「上行」——落点定 (midi, beat)，鸟数定力度，驻留定时值。
  0 只鸟 → 音不存在。空树静默。**客鸟同规则**：落在哪棵树，就是哪棵树声部的音。
- **换季 → 枝干重构**：枝干生长/收缩到新和弦内音，栖鸟就近换枝
  （即现有 chord-change requantize，有了形体）。
- **扫描线 = 一缕光/风扫过树冠**：扫到的枝干发亮、栖鸟振翅鸣叫。
  时钟仍在 transport（G1/G2 不变）。
- **引导/驱赶鸟群 = 实时编曲**：用户做的是生态动作（赶鸟、聚鸟），
  编曲变化是映射层翻译的结果。无接管按钮、无拖 anchor。

## 4. boids 去哪了：一套鸟群的三重身份

**只有一个世界**，每群鸟绕自己的树生活，一部分栖着、一部分飞着。
同一套 boids 三重身份：

1. **栖着的鸟 = 乐谱**（§3）。
2. **飞着的鸟 = 音色**——环绕树冠的「光环」，8D 关系经映射层进音色。
3. **起落 = 编曲的变化**——agent 旋钮、昼夜、用户引导改变栖/飞比例。

**Instrument 层 = 镜头贴近这棵树**，不是另一个页面：

- camera = {cx, cy, scale}，单 canvas；双击某树 → 镜头插值跟随；u ∈ [0,1] 驱动
  LOD 交叉淡化（其他树退为远景暗影，本树显出枝干音高标注与个体鸟）与 UI 透明度。
- **近景交互**：键盘 A..K = **召唤**——按键 → 一只飞鸟落到对应枝干当前拍位 =
  录音环写谱（G5）。声音即时发出，鸟随后飞落追认动画。拖拽 = 塑形光环 → 音色。
- **状态机由 u 对齐**：u > 0.5 进入引擎层语义；u 回 0 自动交还
  （修复「返回不交还」bug）。音频连续性天然成立。

## 5. 昼夜与四季：自然的节律

昼夜与季节是**生态层变量**，音乐后果全部经映射层（§2 表）：

- **昼夜**：入夜鸟归栖入眠、世界变暗，**树在夜间回复加速**（休养流量）；白天活跃。
  一个昼夜 8–16 bar（master 可调）。
- **晨鸣（dawn chorus）**：每个黎明各群短暂齐活跃——真实鸟类学现象，
  免费的每日高潮与段落结构（保留的唯一全局作息事件）。
- **季节**：换季 → 枝干重构 + 世界色调/枝叶变化 + **虫害滋生率变化**（夏快冬慢）
  ——于是夏天啄木鸟自然忙碌、冬天全局趋静，季节性编曲从经济涌现。
  用户在 HUD 换和声 = 人工干预气候。

## 6. Agent：目标是让四棵树活下去

### 6.1 树健康经济——唯一记分牌（纯生态词汇）

每棵树的健康是五个流量的积分：

| 流向 | 流量（全部可视） |
|-|-|
| **进** | 斑鸠沃土（稳定栖驻）；百灵传粉（穿飞经过）；休养（低占用自愈，夜间加速） |
| **出** | 虫害啃食（随季节滋生，唯啄木鸟可清）；鹈鹕压枝（重栖）；过载（占用超容量、种群过密） |

- 树健康低 → 枝叶褪色枯萎（映射层：该声部干瘪、cutoff 暗沉、lofi 加重）。
- 全局健康 = 四树均值；归零不判负，进入「寒冬」等 master 救场
  （换季+补鸟——翻译出来正好是一次转段）。
- 「每树有栖鸟」「种群均衡」不再是显式规则——弃树被虫害拖垮、过密触发过载，
  都从流量自然涌现。

**agent 的目标**：让树活下去。仅此而已。它的输入、规则里的每个词、每个流量
都是生态量；「这样出来的音乐为什么成立」由映射层（§2）和音乐底层负责回答。

### 6.2 种群 agent（每树一个，本地 LLM，每 1–2 bar）

5 条规则，按优先级（右列仅为设计注解，**agent 不可见**）：

| # | 生存规则（生态词汇） | 映射层翻译出的后果 |
|-|-|-|
| 1 | 作息：夜间归栖睡眠（全局昼夜） | 昼夜 A/B 段 |
| 2 | 体力：energy 低 → 归栖休息；充沛 → 活跃 | 密度呼吸 |
| 3 | **本职**：执行本种职能——啄木鸟巡查虫害最重的树（含串门出诊）；百灵定期巡飞传粉；斑鸠择弱树久栖沃土；鹈鹕健康不足时节制停驻 | 声部进退、动机交换、bass 自限 |
| 4 | 应答：邻树起落频繁 → 短暂跟随兴奋 | call-and-response |
| 5 | 兜底：cruise，小游走 | 稳定持续声部 |

- **旋钮不变**：set_motion / set_density（栖飞比与占枝档位）/ set_anchor
  （目标区，可指向他树树冠=串门）——映射到现有 Agent Control API，**玮圣接口不用改**。
- energy 单标量：昼夜 + 活动驱动（活动耗能、栖息回能）。
- **G7 韧性不变**：5 条规则同时以纯代码确定性策略兜底；LLM 是「个性层」，
  掉线时代码无缝接管。

### 6.3 Master agent（云端强模型，每 4 bar）＝ 自然，不是恶神

只动环境，永不直接碰种群参数。指令 5 个：

| 指令 | 生态语义 | 后果（经生态涌现） |
|-|-|-|
| `set_population(flock, ±n)`（新增） | 补鸟/减鸟 | 占用概率→密度（无直接映射） |
| `set_daynight(bars)`（新增） | 昼夜周期长度 | 段落速度 |
| `set_scale`（既有） | 换季 | 和声色彩/移调 + 虫害节奏 |
| `set_bpm`（既有） | 气温 | 速度 |
| `spawn_pest_wave(tree, intensity)`（新增） | 扰动工具：向某树注入一波虫害 | 张力段落的起点 |

**目标 = 中度干扰**（v3.3 改，源于生态学的中度干扰假说：生态系统在中等强度扰动下
多样性最高）：不是「健康最大化」，而是**健康保持在带内 + 对「过于稳定」惩罚**。
太稳=单调，太狠=崩溃，甜蜜点在中间——这句话同时就是音乐陈述。master 不是反派，
是天气：张力-释放循环由目标函数保证出现，不靠运气。

**扰动限速**：`spawn_pest_wave` 有强度上限与冷却（不能快过鸟群的响应速度），
「对抗但限速」——与 at_bar 队列同一思路。

强制 JSON、bar 边界队列、调用预算沿用既定方案。

### 6.4 虫群 agent（P4 可选）＝ 第五个生物

若余力允许，虫害从被动过程升级为**第五个种群 agent**（本地小模型，与鸟群 agent 同构）。
它不想杀树，它想**活着**——对抗从竞争性生存目标涌现，而非恶意（公理 1 对它同样成立）：

| # | 生存规则（生态词汇） | 映射层翻译出的后果 |
|-|-|-|
| 1 | 扩散：向最肥沃、啄木鸟防御最弱的树蔓延 | 杂质音在声部间游走，像慢速的对手声部 |
| 2 | 避敌：啄木鸟出诊时收缩蛰伏 | 杂质音的潮汐退落 |
| 3 | 物候：夏季爆发、冬季蛰伏 | 季节性张力 |

- 无新物理：虫害已是每树标量，agent 只决定它往哪长、何时收。
- 啄木鸟活跃度与虫害水平会自发形成 Lotka-Volterra 式捕食振荡
  ——shimmer 声部与杂质音的自然潮汐，免费的段落结构。
- 同样有纯代码兜底（G7）；掉线时退回 v3.2 的被动滋生过程。
- **明确不做**：拥有「让树死」目标的恶意云端对抗者——目标退化（赢=demo 失败，
  削弱=假对抗）、叙事污染（自然不邪恶）、双倍预算与集成风险。

## 7. 砍掉了什么

| 条目 | 引入于 | 现状 | 理由 |
|-|-|-|-|
| 食物/投食、能量税、天敌 | v2 | **砍** | 后果被昼夜+经济覆盖；30 秒讲不清 |
| 种群规则 8 条 | v2 | **5 条** | 安全/饥饿/稳态并入作息与体力 |
| master 指令 7 个 | v2 | **4 个** | 只留后果可感的 |
| 林地/独立 HP 实体 | v3.1 | **砍** | 健康落到每棵树上，更可视更可讲 |
| chronotype 作息表 | v3 | **砍** | 轮替由生态经济涌现，不靠排班 |
| 种群数→声部厚度直接映射 | v3.1 | **砍** | 种群经占用概率间接影响密度，无需直连 |
| 恶意双云端对抗（想让树死的 agent） | v3.3 讨论 | **不做** | 目标退化、叙事污染、双倍预算；对抗性由中度干扰 + 虫群生存目标承担 |
| 进化层 | — | 长线 | — |

判据统一：机制的后果必须在画面和声音上双重可感，否则删。

## 9. 开放问题

1. 同一 (枝干, 步位) 容量：倾向 3 只封顶、力度三档。
2. 五流量的速率配平（虫害滋生 vs 啄虫效率 vs 沃土/传粉回复 vs 压枝损耗）：
   需要数值原型，目标是「不干预时四树缓慢波动但不崩」。
   同一原型也要标定 `spawn_pest_wave` 的强度上限与冷却（扰动不能快过鸟群响应），
   以及 master「过稳惩罚」的稳定判据（多少 bar 无显著变化算过稳）。
3. 串门频率与时长：客音符太多会搅浑声部身份；倾向啄木鸟同一时刻最多出诊一棵树。
4. 虫害的可视语言（树干斑点/暗纹）与「杂质音」的量感对应。
5. 传粉航线是否给极轻的风声。
6. 夜间静默占比：倾向昼夜偏短（8–16 bar），夜里留少量守夜鸟不全静。
