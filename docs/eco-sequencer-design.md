# 生态音序器 v3.1：四树一林

> 状态：设计稿（2026-07-18，v3.1）。
> 飞书同步：https://twiddle-ai.feishu.cn/docx/IKXCdw0GUoRzKOxem3OcMvpqnyh
> v3→v3.1 变更：定「四树+共享林地」；规则与声音彻底脱钩——玩法只引用生态中间属性，
> 由固定映射层翻译成音乐。

## 0. 原则

1. **agent 是生物，不是作曲家**——目标函数只用生存词汇定义，音乐是副产品。
2. **生态要成为音序机制本身**，不能只是视觉皮肤。
3. **做减法**：凡是 30 秒 demo 里观众看不见、听不出的机制，一律砍掉
   （食物/能量税/天敌已移出黑客松，见 §7）。
4. **规则与声音脱钩**（v3.1 新增）：HP 增减、鸟种属性、玩法规则**只引用生态中间属性**
   ——栖驻、种群、活跃度、繁茂度、昼夜、季节，全部可视。音乐后果由固定的映射层
   单向翻译。agent 的世界里没有「音」这个字。

## 1. 世界 = 四棵树，一片林地

**四棵树，不是一棵**：每个声部需要独立的「枝干 × 16 步」卷帘面（一棵树叠四套必乱）；
zoom 需要离散目标；守域规则和 population 指令需要领地边界。生态的统一性由
**共享林地**承载：四树围绕中央的水潭/空地，**HP = 林地生机**，可视化在地表植被、
水位、光照上。（美术变体：画成一棵巨树的四根主枝、四个分离树冠区，机制不变。）

一棵树 = 一个声部。树是乐器，鸟群是演奏者，agent 是鸟群的本能。
鸟种属性**全部是生态词汇**（对应现有 4 flock/SPECIES 配置）：

| 树 | 鸟种 | 生态属性（体型 · 作息 · 栖性） | 映射层接入的声部 |
|-|-|-|-|
| 低吟树 | 鹈鹕 | 体型大、飞得慢、群小；黄昏最活跃；一栖很久 | bass（长低音） |
| 和鸣树 | 斑鸠 | 温顺恋巢；全天平稳；栖飞各半 | support（pad 铺底） |
| 飞羽树 | 百灵 | 轻捷、群大、爱高飞；清晨最活跃（晨鸣主角） | ornament（lead） |
| 微光树 | 啄木鸟 | 贴干短飞；白天最活跃；驻留短促频繁 | shimmer（pluck） |

- 四个作息（chronotype）错开 → 一天内声部自然轮替，编曲对位从生态属性涌现。
- 脱钩原则的示范：啄木鸟「驻留短促频繁」是生态习性，映射层自然翻译出断奏
  ——不存在任何「啄木鸟=短音」的声音规则。
- shimmer 声部是音高化短音（合成 pluck），不是采样鼓——鼓 lane 维持已删除状态。

## 2. 三层结构：生态层 → 映射层 → 音乐底层

| 层 | 内容 | 谁在这里活动 |
|-|-|-|
| **生态层** | 鸟、树、林地。状态变量：栖驻（哪根枝、几只、多久）、种群数、活跃度（栖飞比与光环运动）、**繁茂度**（每棵树）、昼夜相位、季节、林地生机（HP） | 规则、HP、agent、用户交互——全部只在这层 |
| **映射层** | 固定的、手工调校的单向翻译（下表）。agent 永不触碰 | 无人。它是「乐器的构造」 |
| **音乐底层** | 和弦内量化、音域带、微变化预算、G1/G2 时钟 | 无人。保证映射输出的任何组合都成立 |

**繁茂度**（v3.1 新增的关键中间属性）：每棵树的枝叶茂盛程度，慢速积分器
——有鸟栖驻缓慢变茂，长期弃树逐渐枯萎。它是「这棵树被照料程度」的可视记忆，
既是 HP 的输入，也是映射层的输入。

**映射层对照表**：

| 生态量（全部可视） | 音乐参数 |
|-|-|
| 栖驻位置（枝干 × 步位） | 音高 × 拍位 |
| 同点栖鸟数（上限 3） | 力度三档 |
| 驻留时长 | 时值 |
| 光环 8D 运动（紧密/对齐/扩张/动能/环流） | 音色（滤波亮度/失谐/空间感/电平/共振） |
| 树的繁茂度 | 该声部丰润度（混响发送、谐波丰度） |
| 种群数量 | 声部厚度 |
| 昼夜相位 | 滤波宏 + 整体密度上限（夜暗而稀） |
| 季节 | 和弦色彩（春大三/夏 sus4/秋小七/冬小三）→ 枝干重构 |
| 林地生机（HP） | 全局混响湿度、整体亮度 |

「生态健康 ⇔ 编曲良好」的对应关系**只存在于这张表的设计里**：
均衡的栖驻分布翻译出配器均衡，起落应答翻译出对位，作息节律翻译出段落。
规则和 agent 从不引用右列。

## 3. 树 = 乐器：枝干即音符行

映射层的「下行」：和声决定树的形态。

- **枝干 = 和弦内音**：声部音域带（`bandForChord`）内每个和弦内音长一根枝干，
  高度 ∝ 音高。枝干只长在和弦内音上——「怎么落都不难听」在树的形态里就位。
- **沿枝方向 = 循环时间轴**：16 步格点。一棵树冠 = 该声部的钢琴卷帘。
- **鸟落枝 = 音符**：映射层「上行」——落点定 (midi, beat)，鸟数定力度，驻留定时值。
  0 只鸟 → 音不存在。空树静默。
- **换季 → 枝干重构**：枝干生长/收缩到新和弦内音，栖鸟就近换枝
  （即现有 chord-change requantize，有了形体）。
- **扫描线 = 一缕光/风扫过树冠**：扫到的枝干发亮、栖鸟振翅鸣叫。
  时钟仍在 transport（G1/G2 不变）。
- **引导/驱赶鸟群 = 实时编曲**：用户做的是生态动作（赶鸟、聚鸟），
  编曲变化是映射层翻译的结果。无接管按钮、无拖 anchor。

## 4. boids 去哪了：一套鸟群的三重身份

「两套模拟」问题在 v3 起彻底消失：**只有一个世界**，每群鸟绕自己的树生活，
一部分栖着、一部分飞着。同一套 boids 三重身份：

1. **栖着的鸟 = 乐谱**（§3）。
2. **飞着的鸟 = 音色**——环绕树冠的「光环」，8D 关系经映射层进合成器参数。
3. **起落 = 编曲的变化**——agent 旋钮、昼夜、用户引导改变栖/飞比例。

**Instrument 层 = 镜头贴近这棵树**，不是另一个页面：

- camera = {cx, cy, scale}，单 canvas；双击某树 → 镜头插值跟随；u ∈ [0,1] 驱动
  LOD 交叉淡化（其他树退为远景暗影，本树显出枝干音高标注与个体鸟）与 UI 透明度。
- **近景交互**：键盘 A..K = **召唤**——按键 → 一只飞鸟落到对应枝干当前拍位 =
  录音环写谱（G5）。声音即时发出，鸟随后飞落追认动画。拖拽 = 塑形光环 → 音色。
- **状态机由 u 对齐**：u > 0.5 进入引擎层语义；u 回 0 自动交还
  （修复「返回不交还」bug）。音频连续性天然成立。

## 5. 昼夜与四季：自然的节律

昼夜与季节是**生态层变量**，音乐后果全部经映射层（§2 表）：

- **季节**：换季 → 枝干重构 + 世界色调/枝叶变化。用户在 HUD 换和声 = 人工干预气候。
- **昼夜**：入夜鸟归栖入眠、世界变暗；白天活跃。一个昼夜 8–16 bar（master 可调）。
- **晨鸣（dawn chorus）**：每个黎明各群短暂齐活跃——真实鸟类学现象，
  免费的每日高潮与段落结构。
- 四个 chronotype 错开：清晨百灵领奏、白天啄木鸟点缀、黄昏鹈鹕渐厚、夜里斑鸠独守。

## 6. Agent：目标是让林地活下去

### 6.1 林地生机 HP——全场唯一记分牌（纯生态词汇）

| 方向 | 条件（全部可视） |
|-|-|
| **+** | 每棵树都有栖鸟；各树种群处于健康区间且分布均衡；夜间归栖率高（作息被遵守）；起落应答波（一群起飞后邻群短暂跟随起落） |
| **−** | 弃树（长期 0 栖鸟 → 该树繁茂度枯萎）；四群同时全体高活跃（林地过载）；某树种群过密或过疏 |

HP 低 → 林地枯萎、植被褪色（映射层：混响变干、整体渐弱）；HP 归零不判负，
进入「寒冬」等 master 救场（换季+补鸟——翻译出来正好是一次转段）。

**agent 的目标**：让林地活下去。仅此而已。它看到的输入、它规则里的每个词、
HP 的每一项都是生态量；「这样出来的音乐为什么成立」由映射层（§2）和音乐底层负责回答。

### 6.2 种群 agent（每树一个，本地 LLM，每 1–2 bar）

5 条规则，按优先级（右列仅为设计注解，**agent 不可见**）：

| # | 生存规则（生态词汇） | 映射层翻译出的后果 |
|-|-|-|
| 1 | 昼夜作息：按本种 chronotype 决定栖/飞比例 | 声部轮替、A/B 段 |
| 2 | 体力管理：energy 低 → 归栖休息；充沛 → 活跃 | 密度呼吸 |
| 3 | 守域：留在己树树冠 | 音区稳定、声部分层 |
| 4 | 应答：邻树近期起落频繁 → 短暂跟随兴奋 | call-and-response |
| 5 | 兜底：cruise，小游走 | 稳定持续声部 |

- **旋钮不变**：set_motion / set_density（栖飞比与占枝档位）/ set_anchor（树冠内目标区）
  ——映射到现有 Agent Control API，**玮圣接口不用改**。
- energy 单标量：昼夜 + 活动驱动（活动耗能、栖息回能），无食物/税输入。
- **G7 韧性不变**：5 条规则同时以纯代码确定性策略兜底；LLM 是「个性层」，
  掉线时代码无缝接管。

### 6.3 Master agent（云端强模型，每 4 bar）＝ 自然

只动环境，永不直接碰种群参数。指令 4 个：

| 指令 | 生态语义 | 映射层翻译出的后果 |
|-|-|-|
| `set_population(flock, ±n)`（新增） | 补鸟/减鸟 | 声部厚薄 |
| `set_daynight(bars)`（新增） | 昼夜周期长度 | 段落速度 |
| `set_scale`（既有） | 换季 | 和声色彩/移调 |
| `set_bpm`（既有） | 气温 | 速度 |

目标：HP 最大化。强制 JSON、bar 边界队列、调用预算沿用既定方案。

## 7. 砍掉了什么

| 条目 | v2 | v3 起 | 理由 |
|-|-|-|-|
| 食物/投食 | P4 | **砍** | master 抓手改为 population；后果已被昼夜+HP 覆盖 |
| 能量税 | P3 | **砍** | 重复机制 |
| 天敌 | 阶段 2 | **砍出黑客松** | 30 秒 demo 讲不清 |
| 种群规则 | 8 条 | **5 条** | 安全/饥饿/稳态并入作息与体力 |
| 能量经济 | 食物+税+代谢 | **单标量** | 输入源砍掉后自然简化 |
| master 指令 | 7 个 | **4 个** | 只留后果可感的 |
| 进化层 | 长线 | 长线 | — |

判据统一：机制的后果必须在画面和声音上双重可感，否则删。

## 9. 开放问题

1. 同一 (枝干, 步位) 容量：倾向 3 只封顶、力度三档。
2. 夜间静默占比：倾向昼夜周期偏短（8–16 bar），夜里留斑鸠独奏不全静。
3. 枝干数量：和弦内音 × 音域带可能 8–12 根，是否按八度合并显示。
4. 繁茂度的时间常数（多少 bar 从弃树到枯萎可见）与它进混响发送的曲线，需试听调参。
5. 驱赶手势形式（点击惊飞 / 拖拽气流），原型试玩定。
