# 空间控制与声音关系契约

> 这是 MVP 的固定因果表。改参数名可以，不能在没有更新本文、测试和界面说明的情况下改变因果关系。

## 一句话

二维地图负责演奏，鸟群关系负责音色：`X=循环时间位置`，`Y=音高`；每个 Flock 的八种关系经过语料 SVD 映射进入该 Voice 的 RAVE/BRAVE latent。

## 两条互不混用的链

```text
群组 X / Y / 横向宽度 → PULSE 触发 / Dorian 音高 / note duration

群内 + 群间 + 障碍关系 → 8D relation state → SVD 安全尺度 → latent step → decoder
```

XY 不再直接控制 latent。音高、时值也不反过来改变 Boids。

## 固定的 8D 关系状态

每个 Flock 汇总为一个 `[-1, 1]` 的 8D 向量：

| # | 名称 | 大白话 | 主要由什么改变 |
|---:|---|---|---|
| 1 | 紧密 Compactness | 鸟挤在一起还是散开 | 聚合、分离、感知半径、障碍 |
| 2 | 对齐 Alignment | 大家是否朝同一方向飞 | 对齐、引导、转向力度 |
| 3 | 扩张 Expansion | 这一刻正在聚拢还是向外炸开 | 聚合、分离、障碍、群间碰撞 |
| 4 | 运动能量 Motion Energy | 整群飞得慢还是快 | 巡航速度、引导、游荡幅度 |
| 5 | 环流 Circulation | 群内是在顺/逆向绕圈还是直行 | 转向力度、障碍、游荡 |
| 6 | 湍流 Turbulence | 个体速度差小还是彼此混乱 | 对齐、分离、游荡、障碍 |
| 7 | 群间压力 Inter-flock Pressure | 最近的另一群是否逼近 | 群的位置、群间分离、引导 |
| 8 | 障碍压力 Obstacle Pressure | 有多少鸟正在被迫绕行 | 障碍的位置、半径和鸟群路径 |

前 8 个语料 SVD 方向分别接收这八个关系信号，但这些方向不冒充 brightness 等固定语义。16D decoder 的后 8 维只接收八种关系的确定性交互项，幅度更小；8D decoder 直接使用八种关系。Species 的语料均值仍是音色身份锚点。

## 当前旋钮到底改变什么

| 控制 | 直接改变 | 主要可见关系 | 不直接改变 |
|---|---|---|---|
| 巡航速度 | 鸟的速度上限 | 运动能量、对齐、湍流 | 音高、latent 数值 |
| 转向力度 | 每步最大转向力 | 对齐、环流、障碍响应 | note duration |
| 感知半径 | 同群看见伙伴的距离 | 紧密、对齐 | decoder 参数 |
| 贴身距离 | 所有近鸟开始避让的距离 | 紧密、扩张、群间压力 | 声像 |
| 分群距离 | 哪些鸟算一个 note group | 音符数量、横向宽度 | 8D 音色关系 |
| 最小成组 | 过滤多小的孤立群 | 音符数量 | Boids 运动、latent |
| 聚合 | 朝同群局部中心转向 | 紧密、扩张 | 音高 |
| 对齐 | 靠近同群平均速度 | 对齐、湍流 | 时值 |
| 分离 | 过近时互相避让 | 紧密、扩张、群间压力 | 模型选择 |
| 游荡幅度 | 低频自主转向力 | 环流、湍流、运动能量 | 随机 latent 抖动 |
| 游荡速度 | 自主转向方向变化频率 | 环流、湍流 | BPM、触发速度 |
| 迁徙响应 | latent 每个公共音频块的最大步长 | 音色追赶关系目标的快慢 | Boids 运动 |

`分群距离`和`最小成组`属于空间解释器，不进入 8D 音色状态。`迁徙响应`是唯一直接作用于 latent 路径的安全/表现控制，其输入仍然是关系目标而不是手调音色维度。

## 自主变化的边界

游荡是有 seed、低频、有惯性的转向力。它先改变运动，再改变可测关系，最后改变 latent；系统不会逐帧向 latent 注入随机数。因此相同 seed 和操作仍可重放，放手后世界又不会完全静止。

## 音符层

- PULSE 扫到某个 note group 的 X 位置时，只触发该 group；
- group 的 Y 位置量化到当前 Dorian 音级；
- group 的横向宽度映射为时长；
- 一个连通 group 是一个音，空间分裂后最多四个音；
- 一个 Flock 仍只做一次 neural decode，复音是 decoder 后的独立 pitch/envelope 分支。

## 修改闸门

以后要改变这套关系，必须同时回答：用户能否从画面预判声音、同一动作能否复现、与现有维度是否重复、是否仍然只靠空间行为控制。四项没有证据时，不新增音色维度或隐藏规则。
