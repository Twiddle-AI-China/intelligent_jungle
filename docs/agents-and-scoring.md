## 1. 一句话世界观

四棵树、四群鸟；**栖落即发音**。鸟只管起落习性，树有偏好节奏得分；
**和声只有一个作者（master）**——它广播框架与张力，树 agent 在框架内选枝，绝不各自定调。

---

## 2. 时间尺度

| 单位 | 定义 | 谁在动 |
|------|------|--------|
| **拍** | 驻留、预算、计分「平均驻留」的单位 | flock 计划 `dwellBeats`；world 按 BPM→秒 |
| **小节** | 活跃窗；一昼夜 = 4 小节 4/4 | flock 计划 `activeBars`；物种 `activityBars` |
| **循环 / 昼夜** | 1 天 = 1 loop = 16 拍（默认）；乐句保持按「循环数」计 | flock `holdLoops`；transport / BPM 派生日长 |
| **季** | **一个根音和弦**，长 **8–16 昼夜**（master 在菜单内定长） | 换季 = 进行走一步 + 骨架枝大迁移（稀有） |
| **年** | 四季串成一条四和弦进行 | master 菜单里的季节序 |

**昼夜黎明不换根音和弦**——只换同根下的**色彩档**（明暗呼吸）。
骨架枝整季不动；色彩枝可每日微调。

---

## 3. 四树性格与偏好带

行为分唯一机制：三日观测量落在偏好带内满分，带外线性衰减（单位：换枝=次/循环，驻留=拍）。

| 树 | 角色 | 换枝/循环 | 平均驻留 | 群聚 | 附加性格 |
|----|------|-----------|----------|------|----------|
| melody 飞羽 | 旋律线 | 高 8–16 | 短 0.5–2 拍 | 1 | 单音性；乐句保持 H 循环；忌连重复枝 |
| pad 和鸣 | 铺底 | 极低 0–1 | 长 ≥8 拍 | 1–2/枝、铺多枝 | 日内少换，日界成批搬家 |
| bass 低吟 | 低音锚 | ≈0（**仅换季**） | 极长 ≥1 循环 | 1–2，**限骨架/低枝** | 认 skeleton；换季日前聚集、次日领迁 |
| texture 微光 | 纹理 | 中 4–8 | 中短 1–4 拍 | 1 | 喜离枝再回同一枝 |

对 `harmonicFrame` 的固定读法：

| 树 | 读 frame |
|----|----------|
| melody | tension 低→守骨架、保乐句；高→可上色彩枝、缩短 dwell |
| pad | 按 `color.notes` 加权选长音簇（色彩=明暗） |
| bass | 只认 `skeleton`；`seasonDay == seasonLength-1` 预告换季 |
| texture | tension → 敲击/换枝密度 |

## 4. 单树（flock）agent 决策回路

**分权**：flock **永远不碰和声**——只编排本声部行为（家枝、活跃窗、dwell、密度、对偏好带偏离的修正）。

### 4.1 时序（评估流水线）

| 时刻 | 动作 |
|------|------|
| 第 N 天日间 | 鸟按本能物理演奏；累计当日统计与行为分 |
| 第 N 天（复盘窗） | 并联 dayReview：复盘 **第 N−1 天**完整数据 → 产出计划（LLM∥规则） |
| 第 N+1 天黎明 | 领取计划；与 master 的 `harmonicFrame` **一同生效**；未就绪→规则兜底 |

日内 **不** 连续改 urge；变奏只在日界。

### 4.2 计划契约（音乐单位）

```
{ dwellBeats, activeBars, holdLoops, mutations[] }
```

| 字段 | 含义 |
|------|------|
| `dwellBeats` | 单次驻留尺度（拍） |
| `activeBars` | 当日活跃相关小节预算（与物种活动窗求交） |
| `holdLoops` | melody：乐句保持循环数（config 范围自选，默认 4） |
| `mutations[]` | 家枝小变异 `{from,to}`；保持期内清空；幅度封顶、邻枝优先 |

### 4.3 观测 → 评估 → 计划

1. **观测**：换枝率、平均驻留拍、群聚峰值；可选 ecology 偏离方向；`harmonicFrame.tension` / 落枝与骨架·色彩关系。
2. **评估**：行为分（偏好带）+ 理由句（「换枝偏低 → 明日放宽活跃」）；不另设反停滞机制。
3. **计划**：修正偏离 + 少量家枝变异；melody 在 H 个完整循环内冻变异，期满小变。
4. **黎明生效**：写 homeBranch / density / dwell / active；骨架大迁移**仅换季**；色彩档由 master 当日选定后映射到色彩枝。

决策源标注：规则层 / LLM（+ 外部 master 通道若启用）。掉线不挡节拍。

## 5. Master 决策回路与 `harmonicFrame`

**分权**：和声全局结构 **唯一作者** = master（「季节/天气」）。

### 5.1 只点菜，不发明菜

菜单全部人定进 config（季节序与每季骨架和弦、每季色彩档盘、季长范围 8–16、张力可选档、冷却天数）。
master 只选：换季与否、季长、**今日色彩档**、**今日 tension**；每次大结构变化尽量只动一维。

### 5.2 每黎明广播（现有 dawn 通道扩字段）

```
harmonicFrame: {
  season, seasonDay, seasonLength,
  skeleton: { root, notes },   // 整季不变
  color: { id, notes },        // 今日色彩档
  tension: 0..1                // 今日张力预算
}
```

master **不**指定谁唱哪音——只给框架 + 预算；树在框架内选枝（枝=音，具身性保留）。

### 5.3 Master 三观测量（决策依据，不另增资源概念）

| 项 | 含义 | 效果 |
|----|------|------|
| **均衡** | 四树行为分（及观测中的 H）均值与最低值是否在健康带 | 某声部持续低分 → 倾向换色彩档 / 调 tension / 到期换季 |
| **新鲜** | 同一季·同一色彩连续越久越腻 | 季长在 8–16 内涌现，不写死单日 |
| **平稳** | 一次只改一维；换季后冷却 | 大结构低频，听感不乱 |

### 5.4 决策源顺序

`external → llm → policy` 兜底。规则兜底：季内顺行色彩/张力策略 + 到期换季。

## 6. 计分体系

### 6.1 行为分（economy，已定）

- 三观测量 × 偏好带 → 树日行为分 ∈ [0,1]；侧栏长势显示。
- flock 日评估吃偏离方向；LLM 只拿这些数做偏置。

### 6.2 和谐分 H（目标态 · 第一轮）

| 落枝相对 frame | 贡献 |
|----------------|------|
| 骨架枝 | 1.0 |
| 色彩枝 | 0.7 |
| 框架外 | 扣分 |

H ∈ [0,1]，**每树每天**统计。

**第一轮（已拍板）**：H **只观测显示 + 喂给 master dayReview**，**不乘进** economy 行为分。跑出数值分布后再决定是否 `行为分 × H` 耦合。

### 6.3 张力预算与闭环（目标态）

- master 的 `tension` = 今日允许多大比例落色彩枝（及对框架外的容忍）。
- **第二轮候选**：超预算 → `harmonyDeviation` 扣长势；贴合 → 加分；master 据各树 H/超支调次日 tension。
- **第一轮**：张力仍由 master 广播并约束选枝语义；deviation 耦合暂缓。

### 6.4 概念净账

新增：骨架/色彩枝、张力预算、和谐分 H。删除：每日和弦步进。净增 2。

## 变更记（被取代的旧语义）

旧「**每昼夜 = 和弦进行走一步**、季短且季=色彩系」已废弃 → 现「**季 = 单和弦 8–16 天，昼夜 = 色彩档**」；旧 master「跳 progression 步」改为「换季 / 选色彩 / 定 tension」。melody 记忆点改为：骨架稳定下 motif 保持，色彩日呼吸，而非每日根音迁移。

音色 v3 拍板（docs/audio-voices-v3.md，2026-07-19）：pad 减法铺底**保留**、bass 换 **Karplus-Strong 琶音器**、melody FM 短句、texture granular——区分来自发声原理而非仅 EQ。

和谐分 H 第一轮「只观测不进分」**已实施**（2026-07-19）：发音秒按骨架 1.0/色彩 0.7/框架外 0 加权，挂 dayReview / masterInput.observations.harmonyScores / latestEcology（harmonyScore）三通道；`行为分 × H` 耦合仍待数值分布后拍板。
