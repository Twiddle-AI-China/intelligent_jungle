## R1 分数显式 + 电平入分

- **显式**：长势面板不再只一个百分比——每树显示三维（换枝/驻留/群聚）各自的实测值 vs 偏好带 + 各维得分 + 总分（公式在 economy.js，全链数字可溯源）；master 侧行也显示其决策依据的三观测量值。
- **电平入分**：每声部当天 RMS/峰值（audio 层有现成分析位）作为第四维观测进 economy 或 H 修正——设计方向：响度明显失衡（过响/过静）的声部扣分。倾向进 economy 第四维（weights 重归一），具体阈值先观测一轮真实 RMS 分布再定，防止拍脑袋参数。
- 产出顺序：先做显式（纯显示，无风险），电平先观测记录→定阈值→再入分。

## R2 跑几轮真实日志诊断 agent 规则/prompt 与 PRD 对齐

- 依据文档 = docs/agents-and-scoring.md（唯一 PRD 读物）+ eco-incentive-design.md §6。
- 方法：浏览器实跑 ≥10 昼夜两轮（一轮 bird_agent 在线、一轮纯规则），收集全部决策日志与分数轨迹；
- 诊断清单（每条判 ALIGNED/DEVIATED 给证据）：
  - 规则层四启发（散巢/漫游/密度/驻留）触发频率与 PRD 意图是否一致；
  - LLM flock：偏离偏好带时提议率、提议质量（T25 直探已知基线）；保持期语义；
  - master（LLM/policy 两态）：三观测量决策与 §6 表格逐项对照；
  - 分数轨迹：四树分是否可闻可感地反映在行为上（分数→行为→分数闭环是否成立）。
- 产出：诊断报告 + 发现偏差时的修复提案（不擅自改）。

## R3 各声部特写的声音调节选项

- Phase 4 树特写（zoom=USER）里给该声部的调节控件：响度（gain）、EQ（低/中/高三段搁架）、FX（混响发送量；各声部特有参数一档——如 bass 琶音密度上限、texture 粒数上限、melody 句长）；
- 实时生效、存 config/内存（不写盘也行）；UI 用现有树卡片风格的小型竖排滑杆组，出现在特写态的侧缘，退出特写隐藏；
- 约束：只调该声部，不碰 master 总线；调参不动 agent 决策（纯听感层）。
